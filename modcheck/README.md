# Modcheck
Check if mods in a Modrinth collection is available for a version of Minecraft.

## Installation
The program is intended to be installed as an [uv](https://docs.astral.sh/uv/) tool:
```bash
uv tool install git+https://github.com/the-sh4d0w/tools#subdirectory=modcheck
```

## Updating
Updates are also done through uv:
```bash
uv tool upgrade modcheck
```
